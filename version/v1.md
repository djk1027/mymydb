[English]
v0 engine and v1 tooling of mymydb, a small in-memory relational database.

v0 — query engine
- Split into parser / optimizer / executor per DESIGN.md
- SQL: CREATE TABLE, INSERT, SELECT (+ projection), WHERE (= != < <= > >=, AND/OR, parens)
- Storage: in-memory tables (row arrays), INT/TEXT types
- Executor: full scan + WHERE filter; optimizer always full-scans
- CLI: stdin/REPL with .tables/.schema/.help/.exit

v1 — tests, benchmark, stability
- Restructured by responsibility: src/{parse,optimize,execute,storage,cli}
- tests/: zero-dep suite (make test, 10066 checks) — overflow rejection,
  100k-row insert, large/filtered select, error paths, string escaping
- bench/: benchmark runner (make bench [N]) — insert/scan/selectivity throughput
- make memcheck: valgrind leak check (leaks fail the build)
- Parser uses an arena allocator, eliminating AST leaks on error paths (valgrind clean)
