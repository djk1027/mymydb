# version/

실행(execution)마다 결과를 한글/영어로 정리해 이 디렉터리에 저장합니다.
각 파일의 내용은 그대로 git 커밋 메시지로 사용할 수 있는 형식입니다.

- 실제 `git commit` / `git merge`는 이 저장소 작업자(사용자)가 직접 수행합니다.
- 어시스턴트는 커밋/머지를 직접 하지 않고, 결과 정리본만 여기에 남깁니다.

---

Each execution's result is summarized here in Korean/English.
Every file is written so its contents can be used directly as a git commit message.

- The actual `git commit` / `git merge` is performed by the repo owner (the user).
- The assistant does not commit/merge directly; it only records the summary here.
