- 데이터 파일 db별 분리: 각 db는 data/<db>.mdb에 자체 슈퍼블록+카탈로그+데이터.

[English]
Implements DESIGN.md v2.2: per-database files, in-memory removal, a base-path
layout, semicolon-free meta commands, and per-task test timing.

Features
- Meta commands (SHOW/SET/USE/HELP/EXIT/QUIT/CHECKPOINT) run on Enter without a
  ';'; DML/DDL (CREATE/INSERT/SELECT/DELETE) still need ';'. The REPL decides by
  the first word.
- In-memory mode removed: always file-backed. db_new() is gone; only
  instance_open(base) remains.

Design
- Base path: $MYMY/mymydb (or $HOME/mymydb when $MYMY is unset), holding bin/
  (binaries) and data/ (data files). Precedence: CLI argument > mymy.conf
  base_path > $MYMY > $HOME. Directories are created (mkdir -p).
- bin/ placement: the build output is bin/mymydb (so when the working tree is
  the base, it already sits in <base>/bin). `make install` copies it to another
  base's bin/ ($MYMY/mymydb or $HOME/mymydb; override with `make install
  BASE=/path`). The base holds bin/ (binaries) and data/ (data files), with no
  loose binary at the base root.
- Per-database files: each database is a self-contained data/<name>.mdb
  (superblock + catalog + data). Instance metadata (global params, next_db_id,
  db list) lives in data/_master.
  → storage split: serialize.{h,c} (Buf/Rdr), dbfile.{h,c} (per-db file I/O),
    a database now owns its pager/catalog, and the instance coordinates + master.
- Relaxed checkpoint: per-insert -> on shutdown (db_free) + an explicit
  CHECKPOINT command. Blocks stay in the in-memory buffer, so bulk inserts stay
  fast (which is what makes removing in-memory mode viable).
- Tests print each task's wall-clock time (ms).

Tooling / docs
- tests: a temporary-base harness (db_new opens a temp dir), per-task timing in
  RUN, a new test_perdb_files (per-db files exist + reload), and the
  persistence/block-size tests moved to base directories. make test passes
  (10212 checks, with per-task timings); make memcheck is valgrind-clean
  (0 leaks / 0 errors); the benchmark uses a throwaway base (throughput holds).
- mymy.conf: data_file replaced by base_path (commented defaults).
- CLI banner/HELP bumped to v2.2; meta commands documented as needing no ';'.
- Marked DESIGN.md v2.2 headline (완료) per AGENT.md; spec text unchanged.
- git commit / merge performed by the user.
