chore: v1.1 — version 디렉터리 기반 실행 결과 기록 도입

[한글]
실행마다 결과를 한글/영어 커밋 메시지 형식으로 정리해 보관하는 워크플로 도입.

- version/ 디렉터리 신설: 실행별 결과 정리본을 파일로 저장 (그대로 커밋 메시지로 사용 가능)
  - version/README.md: 디렉터리 규칙 설명
  - version/v1.md: v0 엔진 + v1 도구 결과
  - version/v1.1.md: 본 실행 결과
- git commit / merge 는 어시스턴트가 직접 수행하지 않고 사용자가 처리 (DESIGN.md v1.1 규칙)
- DESIGN.md 는 이후 프롬프트 추정을 위해 수정하지 않음
- git 저장소 초기화 상태 확인: master 브랜치, 정상

[English]
Introduce a workflow that records each execution's result as a bilingual
(Korean/English) commit-message file.

- New version/ directory: stores per-execution summaries (usable as-is for commit messages)
  - version/README.md: directory convention
  - version/v1.md: v0 engine + v1 tooling result
  - version/v1.1.md: this execution's result
- The assistant no longer runs git commit / merge; the user performs them (DESIGN.md v1.1 rule)
- DESIGN.md is left unmodified for future prompt inference
- Verified git repo is initialized: on branch master, healthy
