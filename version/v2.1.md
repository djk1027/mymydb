[English]
Implements DESIGN.md v2.1: dot commands removed (MySQL syntax), a parameter
system, and a config file.

Commands (dots removed, normal parsing)
- Removed .tables/.schema/.databases/.help/.exit; replaced with parser-handled
  statements (MySQL syntax), all terminated by ';':
  - SHOW DATABASES / SHOW TABLES / SHOW CREATE TABLE <t>
  - SHOW PARAMETERS / SHOW GLOBAL PARAMETERS
  - SET <name> = <value> / SET GLOBAL <name> = <value>
  - HELP / EXIT / QUIT

Parameters
- Added a ParamStore (name -> value). The instance holds a global store; each
  database holds its own, seeded by copying the global defaults at creation and
  surfaced in table form via SHOW.
- Only two params for now: block_size and data_file (both instance-wide/global).
- Instance-wide settings are global params (SET GLOBAL); per-db settings are db
  params (SET). Parameters are persisted in and restored from the catalog.

Runtime block size
- The BLOCK_SIZE constant became a runtime value (default 8192, range
  512..65536). Block.data is now a pointer, and block_size is threaded through
  table/database/pager/instance.
- Block size is global and applied only when a NEW data file is created;
  existing files use the size stored in their superblock (no runtime re-layout).
  The block size is read from the front of the superblock before the rest is
  interpreted.

Config file mymy.conf
- Reads ./mymy.conf for defaults (key = value, '#' comments). Keys: data_file,
  block_size. Defaults are written as comments for easy editing.
- Precedence: CLI data-file argument > config data_file. With neither, the
  instance is memory-only. Run: ./mymydb [datafile].

Tooling / docs
- tests: test_show_and_params (SHOW/SET/global+db params/HELP) and
  test_block_size_persist (create a 512B file, reopen requesting another size ->
  the file's stored size wins, data + params reload). make test passes (10200
  checks); make memcheck is valgrind-clean (0 leaks / 0 errors); no bench
  regression.
- Updated README; CLI banner/HELP bumped to v2.1; added the mymy.conf template.
- Marked DESIGN.md v2.1 headline (완료) per AGENT.md; spec text unchanged.
