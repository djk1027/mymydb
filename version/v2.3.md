[English]
Implements DESIGN.md v2.3: UPDATE, a B+tree index, and full-scan vs index-scan
performance tests.

UPDATE
- UPDATE t SET col = val, ... WHERE ...: matching rows are collected in one pass,
  then rewritten (delete + re-append) with every index on the table re-keyed
  (delete old entry, insert new).

B+tree index
- CREATE INDEX <name> ON <table> (<col>, ...) / DROP INDEX <name> (multi-column,
  named, non-unique / no PK).
- An index is an object (OBJ_INDEX). Its nodes (root/branch/leaf) live in 8K
  blocks of the database file, extent-allocated, recorded in the catalog and
  reloaded on restart.
- A leaf key is the index-column key plus the row locator (block, slot).
  Appending the locator makes keys unique, so equal column values that straddle
  a leaf split are never missed (fixes the duplicate-key descent problem).
- Keys use an order-preserving encoding (sign-flipped big-endian INT, TEXT bytes
  + 0x00, a per-column null flag) so node comparison is memcmp. Nodes split on
  overflow, promoting a new root as needed.
- Optimizer uses an index for =/range predicates, driven by a single comparison
  or an AND-chain conjunct on the index's first column, with the rest re-checked
  as a residual filter (OR falls back to a full scan).
- Covering: when the query's SELECT/WHERE columns are all in the index, rows are
  served from leaves without reading data blocks.
- INSERT/DELETE/UPDATE keep indexes in sync automatically.

Performance tests (in make test)
- At 100k and 1M rows, time the same point query as a full scan vs an index scan
  and assert the index wins. Observed: ~507x (100k) and ~4907x (1M) faster.

Other
- Makefile: added -MMD -MP header-dependency generation, so editing a header
  (struct layout) recompiles every dependent .c — eliminating stale-object
  layout mismatches.
- tests: added test_update, test_indexes (=, range, text, covering, INSERT/
  UPDATE/DELETE maintenance, DROP), test_perf_100k/1m. make test passes (10540
  checks); make memcheck is valgrind-clean (0 leaks / 0 errors); bench holds.
