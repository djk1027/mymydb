[English]
Implements DESIGN.md v1.3: pressing Enter while the CLI buffer is empty
reprints the `mymydb> ` prompt.

- Previously, hitting Enter on an empty/whitespace-only buffer did nothing but
  accumulate stray newlines; now a blank line re-shows a fresh prompt
- In a line-buffered terminal the `;` and its terminating newline arrive
  together, so the newline immediately following a `;` execution is swallowed to
  avoid drawing a second prompt
  - a swallow_newline flag is set after a `;` runs and consumed by the very next
    blank newline
  - any real (non-whitespace) content on the line clears the flag, so a later
    blank Enter still gets its own prompt
- Multi-line statements do not draw a prompt mid-statement
- Non-interactive (piped) input prints no prompts and still ignores blank lines
- CLI banner/help version bumped to v1.3

Verification

  prompt; a statement prints exactly one prompt (no duplicate); multi-line
  statements show no mid-statement prompt

  item)
